# Marketing UI Kit (uber.com)

Recreation of Uber's corporate marketing surfaces. Black-on-white typography-led layout, big display headlines, two-card hero ("Go anywhere · Get anything"), product grid, and footer.

## Files

| File | Purpose |
|---|---|
| `components.jsx` | Nav, hero, product card, footer |
| `app.jsx` | Page composition |
| `index.html` | Static-style marketing page |
