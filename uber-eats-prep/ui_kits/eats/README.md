# Eats UI Kit

Uber Eats — food marketplace surfaces using Base tokens with the Uber Green accent (#06C167) for primary actions.

Screens:
- **Browse** — search header, location, category pills, restaurant feed
- **Restaurant** — hero photo, info, menu sections, item cards
- **Cart** — line items, fees, place-order CTA

## Files

| File | Purpose |
|---|---|
| `primitives.jsx` | Pills, photo cards, qty stepper, icons |
| `screens.jsx` | Browse, Restaurant, Cart screens |
| `app.jsx` | Navigation shell |
| `index.html` | Interactive prototype |
